# Tembr

Лёгкий аудиоплеер для Linux в духе AIMP: C++17, Qt 6, FFmpeg, miniaudio.

## Что умеет

- **Аудиодвижок**: FFmpeg декодирует всё, что знает (MP3, FLAC, OGG/Opus, AAC/M4A, APE, WV, WMA, WAV, DSD…),
  miniaudio выводит через PipeWire / PulseAudio / ALSA / JACK (выбирается при запуске).
  Точная перемотка, громкость с перцептивной кривой, 5.1 сводится в стерео.
  Файл открывается в фоне: медленный диск или молчащий поток не замораживают окно.
- **Интерфейс**: тёмная тема с оранжевым выделением (или системная), слева крупная обложка
  и название трека, справа плейлисты, внизу панель управления.
- **Интеграция с рабочим столом**:
  - MPRIS: плеер появляется в списке уведомлений GNOME / медиа-апплете KDE с обложкой и кнопками
    «пауза / следующий / предыдущий»; медиаклавиши клавиатуры работают при свёрнутом окне;
  - значок в трее с меню (на GNOME нужно расширение AppIndicator, в Ubuntu оно включено);
    по желанию закрытие окна сворачивает в трей;
  - глобальные горячие клавиши настраиваются в «Файл → Настройки»: на GNOME они регистрируются
    как системные сочетания и работают в любом окне, в том числе на Wayland. Клавиши цифрового
    блока отличаются от цифр над буквами. Обычные клавиши (цифры, буквы, пробел, стрелки) можно
    назначить только вместе с Ctrl, Alt или Super, иначе их нельзя было бы набрать в других
    программах. По умолчанию сочетания действуют, только пока Tembr запущен;
  - название трека на экране при переключении (как OSD в AIMP): на несколько секунд поверх окон
    плавно появляется полупрозрачная подложка с названием, исполнителем, альбомом и длительностью —
    например, после «следующий трек» с горячей клавиши, когда окно свёрнуто. Не берёт фокус
    и пропускает щелчки сквозь себя. В «Файл → Настройки → Название трека» выбирается, когда
    показывать (никогда / окно свёрнуто или скрыто — по умолчанию / окно не активно / всегда),
    где (в любом углу или по центру сверху и снизу, на экране с указателем мыши) и сколько секунд.
    Строки выровнены по центру. При одиночном переключении старое название гаснет и появляется
    новое (без скачков размера); если клавиша «следующий/предыдущий» зажата (переключения чаще
    чем раз в 0,6 с), окно не мигает: текст и подложка меняются одновременно, в одном кадре.
    В сеансе GNOME на Wayland композитор не пропускает щелчки сквозь окна XWayland, поэтому там
    название быстро гаснет, как только указатель подходит к нему ближе чем на ~28 пикселей. Пока
    указатель стоит на этом месте, название не показывается вовсе (при зажатой клавише тоже);
    следующее одиночное переключение снова пробует его показать. С несколькими мониторами
    «экран с указателем» там — тот, где указатель последний раз был над окном X11-программы
    (например, самого Tembr): над окнами Wayland его положение программам XWayland не сообщается.
    Работает в X11 и XWayland (на GNOME Qt-программы работают через него); в сеансе Wayland
    с родным Wayland-плагином Qt (например, KDE) программа не может сама размещать окна,
    и название показывается системным уведомлением;
  - один экземпляр: повторный запуск с файлами передаёт их уже открытому плееру.
- **Плейлисты**: несколько вкладок; чтение M3U, M3U8, PLS, XSPF, CUE, AIMPPL4; запись M3U, M3U8,
  PLS, XSPF, AIMPPL4. В диалоге открытия можно выбрать сразу несколько плейлистов: каждый
  откроется в своей вкладке. Если AIMP установлен под Wine, диалог сразу открывает его папку `PLS`.
- **Пути из Windows и Wine**: `Z:\home\…` → `/home/…`, `C:\…` → `~/.wine/drive_c/…`, диски-разделы
  (`E::` → `/dev/sda2`) → точка монтирования. Учитывается `$WINEPREFIX`.
- **Перемещённая музыка**: «Плейлист → Найти перемещённые файлы…» ищет отсутствующие треки по имени
  в указанной папке (при совпадении имён сравнивается размер) и запоминает, куда переехала папка.
  Следующие плейлисты исправляются автоматически. После импорта с ненайденными файлами плеер
  предлагает это сам.
- **CUE**: образы альбомов раскладываются на треки; кодировки UTF-8, UTF-16, Windows-1251.
- **Теги и информация**: колонки, карточка трека (Ctrl+I) с обложкой и всеми тегами.
- **Сортировка** по клику на заголовок (упорядочивает сам плейлист, как в AIMP),
  **поиск по параметрам** (Ctrl+F):

  | Запрос | Что найдёт |
  |---|---|
  | `queen` | в любом поле |
  | `artist:queen album:"a night at"` | по полям, фразы в кавычках |
  | `year:1970-1979 genre:rock` | диапазон лет |
  | `исполнитель:кино -live` | русские имена полей, исключение |

## Удаление файлов

«Удалить с диска…» в контекстном меню трека (и в меню «Плейлист») удаляет файлы выбранных треков
с устройства после подтверждения: они перемещаются в корзину (`~/.local/share/Trash`, на других
дисках — `.Trash-<uid>` в корне диска), а где корзины нет, плеер предложит удалить безвозвратно.
В окне подтверждения список файлов (имя и папка) открывается кнопкой «Подробнее», а галочка
«Убрать и из всех плейлистов» убирает треки отовсюду (иначе в других плейлистах они помечаются
как отсутствующие; выбор запоминается). Треки уходят из текущего плейлиста, «Локальные файлы»
обновляются сразу. Треки из CUE не удаляются: их файл содержит весь альбом. Треки, файлов которых
нет на диске (например, диск отключён), пропускаются и остаются в плейлистах. Если среди удалённых
играющий трек, сразу включается следующий неудалённый (на паузе — выбирается, но не играет).

Если играющий трек пропал иначе (убран из плейлиста или исчез из «Локальных файлов»), он доигрывает
и остаётся в «Сейчас играет», а затем включается трек, который шёл после него до удаления
(первый из оставшихся); если таких нет — трек, оказавшийся на его месте; иначе плейлист закончился.

## Локальные файлы

Первая вкладка показывает всю музыку из папок фонотеки, как «Локальные файлы» в AIMP. Список
неизменяемый: его можно слушать, искать по нему и сортировать, но добавлять, удалять, переименовывать
и закрывать нельзя, он следует за папками. Файлы, открытые из файлового менеджера, попадают в обычный
плейлист.

Настройки те же, что у фонотеки AIMP («Плейлист → Настройки локальных файлов»):
папки (с подпапками), исключённые папки и слежение за изменениями. При первом запуске они берутся
из `AIMP.ini` (`[MusicLibrary.TAIMPMLLocalDataStorage.SearchOptions]`, пути Wine переводятся),
без AIMP — `~/Music`. Треки сгруппированы по папкам (как `%FileDir` в AIMP). Список кешируется и
обновляется в фоне; теги неизменённых файлов не перечитываются. F5 — обновить вручную.

Сортировка (контекстное меню вкладки → «Сортировка» или щелчок по заголовку колонки) запоминается
и сохраняется при обновлении списка и перезапуске. Помимо обычных полей есть даты:

- **Добавлен** — когда файл появился на этом устройстве (дата создания файла на диске: время рождения
  в Linux, у NTFS через ntfs-3g — `system.ntfs_crtime`). При копировании mtime сохраняется, а дата
  создания — нет, поэтому это именно момент, когда трек попал сюда. Дата запоминается: перемещение
  и правка тегов её не меняют. Порядок строго по времени, до секунды.
- **Изменён** — дата изменения файла. Правка тегов без изменения размера тоже замечается.

Колонки «Добавлен» и «Изменён» включаются в меню заголовка таблицы.

Ширина колонок подбирается по содержимому: каждая получает столько, сколько нужно самому
длинному значению, а свободное место окна делится между всеми пропорционально этой ширине, так что
таблица всегда заполняет окно. Если места не хватает, колонки с ограниченными значениями (№, год,
время, формат, даты) сохраняют свою ширину, а уступают текстовые (название, исполнитель, альбом,
жанр, путь): кому хватает меньше равной доли, получает своё, остальное поровну тем, кому не
хватает. Показанная из меню колонка сразу встаёт на своё место. Перетащенная мышью ширина
запоминается, остальные колонки при этом не меняются, в том числе при смене трека или новых тегах
(место перераспределяется заново, когда колонку скрывают или показывают или меняется ширина окна);
двойной щелчок по границе колонки или «Ширина колонок по
содержимому» в меню заголовка возвращают автоматическую.

## Перенос из AIMP

**В плеере:** «Файл → Импорт из AIMP (компьютер, Android)…» (Ctrl+Shift+I).

- **AIMP на этом компьютере.** Профиль AIMP для Windows ищется в Wine (`~/.wine`, `$WINEPREFIX`,
  `~/.local/share/wineprefixes`), Bottles, PlayOnLinux, Lutris, Steam/Proton, в портативных установках
  и в `%APPDATA%` на Windows. Переносятся именно открытые вкладки в порядке AIMP: список берётся из
  `AIMP.ini` (`[Playlist.Storage]`). Выбирается активная вкладка, отмечается трек, на котором
  остановился AIMP. AIMP оставляет в папке `PLS` старые копии плейлистов (`SD.aimppl4` рядом с
  открытым `SD (2).aimppl4`). Они показываются отдельно, если попросить.
- **Телефон Android по USB.** AIMP для Android хранит плейлисты внутри приложения, поэтому сначала
  сохраните их в файлы: меню плейлиста → «Экспорт» (например, в папку Music). Затем подключите
  телефон в режиме «Передача файлов» (MTP) или с включённой отладкой по USB (ADB). Плейлисты
  (`m3u`, `m3u8`, `pls`, `xspf`, `aimppl4`) ищутся по всей памяти телефона, кроме служебных папок
  других приложений. Понимаются пути `/storage/emulated/0/…`, `/sdcard/…`, SD-карты, `file://`,
  `content://` и пути относительно плейлиста. Подойдёт и любая папка: SD-карта в кардридере
  или копия памяти телефона.
- Треки, которых нет на прежнем месте, ищутся по имени в папке «Музыка на этом компьютере»
  (по умолчанию — папки фонотеки AIMP; несколько папок — через `;`). Если файлов с таким именем
  несколько (`01 - Intro.mp3` в разных альбомах), выбор сужается по папкам альбома и исполнителя,
  затем по размеру. Если однозначно выбрать нельзя, трек остаётся ненайденным, а не подменяется
  чужим. Найденные перемещения папок запоминаются.
- Хранилища телефона распознаются и по названию, и по системным папкам Android, поэтому
  подходят телефоны с любым языком интерфейса и SD-картой. Трек, которого нет в ожидаемом
  хранилище, ищется в остальных. Папка Music на телефоне не обязательна.
- Если включить «старые копии», версии одного плейлиста стоят рядом, новые сверху, с датой
  изменения.
  Треки, которые есть только на телефоне, можно скопировать на компьютер: структура папок
  телефона сохраняется, кроме верхней `Music/`, существующие файлы не перезаписываются.

**Из консоли:** `tembr-migrate`

```sh
tembr-migrate aimp --library /media/Music                    # отчёт: что найдено
tembr-migrate aimp --library /media/Music --out ~/playlists  # записать плейлисты (xspf)
tembr-migrate phones                                         # подключённые телефоны
tembr-migrate android --library /media/Music --copy-to /media/Music --out ~/playlists --format m3u8
```

Без `--out` ничего не записывается. Формат: `--format xspf|m3u8|aimppl4`.

## Сборка

Ubuntu/Debian:

```sh
sudo apt install build-essential cmake ninja-build qt6-base-dev \
     libavformat-dev libavcodec-dev libavutil-dev libswresample-dev
cmake -S . -B build -G Ninja
cmake --build build
./build/tembr [файлы или папки…]
```

Нужны Qt ≥ 6.2 (Widgets, Concurrent, DBus) и FFmpeg ≥ 4.4. Dev-пакеты ALSA/Pulse не нужны.
miniaudio 0.11.21 лежит в `third_party/` (public domain / MIT-0).
Русские подписи стандартных кнопок Qt: `sudo apt install qt6-translations-l10n`.

Чтобы Tembr появился в меню приложений и GNOME показывал его значок в уведомлениях, нажмите
«Добавить Tembr в меню приложений» в настройках или выполните `cmake --install build`.

## Управление из командной строки

```sh
tembr --play-pause | --stop | --next | --previous | --volume-up | --volume-down | --show
```

Чтобы увидеть сообщения FFmpeg о повреждённых тегах и фреймах, запустите с `TEMBR_DEBUG=1`.

Команды управляют уже запущенным плеером через D-Bus (тот же интерфейс использует MPRIS, например
`playerctl -p tembr next`). На KDE, XFCE и других окружениях эти команды можно назначить на клавиши
в системных настройках.

## Формат AIMPPL4

Описан по файлам, сохранённым AIMP 5: UTF-16LE с BOM, CRLF, секции `SUMMARY`, `SETTINGS`, `CONTENT`.
В `CONTENT` строки `-папка` — заголовки групп, трек — 27 полей через `|`:
путь, название, исполнитель, альбом, исполнитель альбома, жанр, год, № трека, № диска, композитор,
издатель, битрейт, каналы (младший байт), частота, длительность (мс), размер, BPM, …, 24 — формат,
25 — комментарий (`\n` вместо перевода строки). Строки с мусором (такие встречаются в старых
файлах AIMP) пропускаются.
